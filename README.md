# Flight Delay Prediction (Team 22)

Predict whether a US domestic flight will arrive delayed by more than 15 minutes, using the 2024 BTS On-Time Performance dataset (~7M rows, 35 columns).

## Pipeline

`main.sh` runs the full pipeline:

1. `scripts/preprocess.sh`: environment setup
2. `scripts/stage1.sh`: Kaggle CSV → PostgreSQL → Sqoop AVRO+Snappy on HDFS
3. `scripts/stage2.sh`: Hive raw external table → Parquet+Snappy partitioned/bucketed → 10 EDA queries with CSV+chart export
4. `scripts/stage3.sh`: Spark ML pipeline on YARN. Logistic Regression and Random Forest, 27-combo grid each, 3-fold CV
5. `scripts/stage4.sh`: Streamlit dashboard
6. `scripts/postprocess.sh`: final checks
7. `pylint scripts`: code quality report

## Data

- Source: Kaggle `hrishitpatil/flight-data-2024`
- Postgres database `team22_projectdb` on `hadoop-04.uni.innopolis.ru`
- Hive database `team22_projectdb` on `hadoop-03.uni.innopolis.ru`
- Final feature table `flights_2024_features`: external, Parquet+Snappy, partitioned by `month`, bucketed by `op_unique_carrier` into 16 buckets, ~7.08M rows

## ML target

`is_arrival_delayed = 1 WHEN arr_delay > 15 ELSE 0`. Cancelled and diverted flights are excluded from training.

## Engineered features

- `scheduled_dep_hour`, `scheduled_arr_hour`: extracted from `crs_dep_time` and `crs_arr_time`
- `is_weekend`: 1 for Saturday and Sunday
- Cyclical sin/cos encoding for hour, day-of-week, month, day-of-month (preserves periodicity)

## Repository layout

- `data/`: dataset CSV files (gitignored, regenerated by Stage 1)
- `models/`: Spark ML serialized pipelines (Stage 3 output)
- `notebooks/`: exploratory notebooks (not part of pipeline)
- `output/`: pipeline outputs including CSVs, charts, logs, schema artefacts
- `scripts/`: pipeline shell and Python scripts
- `secrets/`: `.psql.pass` and `.hive.pass` (gitignored, required to run pipeline)
- `sql/`: `.sql` and `.hql` files

## Requirements

Python packages listed in `requirements.txt`. The pipeline needs a cluster with HDFS, Hive, Spark 3, Sqoop, and a Python venv at `venv/` with packages installed.

`secrets/.psql.pass` and `secrets/.hive.pass` must contain the database passwords.
